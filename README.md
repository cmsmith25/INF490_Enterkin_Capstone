Church Website

A responsive church website developed as a real-world web project using Next.js and JavaScript. The project was designed to provide an accessible, user-friendly online presence with clear navigation and organized content for a church community.

Project Overview

This project was developed as a capstone web development project and resulted in a website for a real church organization. The project involved planning, development, testing, and deployment of a complete website while focusing on usability, responsive design, content organization, and maintainable code.

The project demonstrates experience working with a modern React-based framework and developing a complete website from requirements through implementation.
